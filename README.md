# Maze Solver: Pathfinding Algorithms

A Python project I developed while studying Cognitive Science at Georgia Tech to explore how different search algorithms navigate maze-like environments.

## Algorithms Implemented
- Depth-First Search (DFS)
- Breadth-First Search (BFS)
- Dijkstra's Algorithm
- A* Search

## Project Overview

I implemented and tested these algorithms across seven custom maze environments to compare how they find paths and how efficiently they explore their surroundings.

The project tracks metrics including path length, nodes explored, maximum frontier size, and runtime.
